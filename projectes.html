Com desenvolupo un projecte

Per fer la pàgina web personal vaig seguir aquests passos:

  1. Pensar el contingut de cada pàgina.
  2. Crear els arxius HTML i la carpeta d'imatges.
  3. Escriure el contingut amb els elements HTML.
  4. Comprovar la pàgina amb Live Preview.
